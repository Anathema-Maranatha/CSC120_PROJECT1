# CSC 120 – Project 1: Floridian Tooth Records

Records the teeth of the members of a Florida family (names in a `String[]`, teeth in a
three-dimensional `char[][][]`: one plane per person, one row per layer, one column per
tooth) and offers a menu to print the record, extract a tooth and report the family's
root canal indices (the roots of I·x² + B·x − M = 0).

**Author:** Maxime Manuel Afonso

## Contents
- `FloridianToothRecords/src/FloridianToothRecords.java` – the program (Java, one class, static methods)
- `FloridianToothRecords/javadoc/index.html` – generated JavaDoc pages
- `FloridianToothRecords/design/FloridianToothRecords_StructureChart.jpg` – structure chart (top-down design)
- `FloridianToothRecords/design/FloridianToothRecords_Design.txt` – design algorithm (one module per method)

## Running
Open the `FloridianToothRecords` folder in IntelliJ and run `FloridianToothRecords.main`,
or from a terminal in `FloridianToothRecords/src`:
`javac FloridianToothRecords.java` then `java FloridianToothRecords`.
